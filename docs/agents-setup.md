# הפעלת סוכני Claude בשרת

המדריך מפעיל את שירות `oshit-agents` על ה-VM `apps`, לצד Osh.it. כל צעד מסומן
**אתה** או **Claude**. רק שלושה צעדים הם שלך בלבד, כי הם נוגעים בחשבון, בחיוב
ובסוד: יצירת המפתח, הדבקתו בשרת, והפיכת חבילת התמונה לציבורית.

## מה השירות עושה, ומה הוא לא עושה

- שלושה סוכנים: **שוק** (ג׳–ש׳ 08:41), **הוצאות** (כל יום 07:30), **מחקר** (א׳ 08:22).
  כל אחד אפשר להריץ גם ידנית מהמסך "סוכנים".
- כל הכלים שלהם קוראים בלבד. אין לסוכן כלי שקונה, מוכר, או משנה נתון ב-Osh.it.
- מה יוצא ל-Anthropic:
  - **שוק:** נתוני מחיר ציבוריים, שמות הנכסים ורשימת המעקב, הסטופים והכללים מקובץ
    התיק. לא כמויות ולא שווי.
  - **הוצאות:** סכומים לפי קטגוריה וחודש, סכום החיוב לכל כרטיס (ארבע ספרות אחרונות),
    ופריטים חריגים בלבד. רשימת העסקאות לא יוצאת. הגבול נאכף ונבדק בשרת
    (`server/src/agentContext.ts`).
  - **מחקר:** שמות הנכסים ורשימת המעקב בלבד, וחיפוש ברשת.
- המפתח של Anthropic נמצא רק בקונטיינר הסוכנים. Osh.it עצמו לא מחזיק אותו.

## לפני שמתחילים

כל הפקודות רצות ב-`apps`, בתיקיית ה-stack:

```bash
ssh apps
cd ~/docker/apps-stack
```

---

## 1. מפתח API עם תקרת הוצאה — **אתה**

1. היכנס ל-[console.anthropic.com](https://console.anthropic.com).
2. **Settings → Limits**: קבע תקרת הוצאה חודשית. ההערכה היא 10–25$ לחודש; תקרה של
   30$ משאירה מרווח ועוצרת הפתעות.
3. **API Keys → Create Key**. תן לו שם כמו `oshit-agents`.
4. העתק את המפתח. הוא מוצג פעם אחת בלבד.

## 2. הדבקת המפתח בשרת — **אתה**

```bash
cd ~/docker/apps-stack && umask 077
read -rsp 'Anthropic API key: ' K && printf 'ANTHROPIC_API_KEY=%s\n' "$K" >> .env && unset K
```

- `read -s` לא מציג את מה שמודבק, והמפתח לא נשמר בהיסטוריית ה-shell.
- `umask 077` יוצר את `.env` עם הרשאות קריאה לך בלבד.
- בדיקה שהשורה נכנסה, בלי להציג את המפתח:

```bash
grep -c '^ANTHROPIC_API_KEY=' .env
```

צריך לצאת `1`.

> אל תשלח את המפתח בצ'אט, גם לא ל-Claude. Claude לא צריך לראות אותו בשום שלב.

## 3. טוקן השירות — **Claude**

הטוקן מזהה את שירות הסוכנים מול Osh.it. הוא נוצר בשרת ישירות לקובץ, בלי להופיע
על המסך:

```bash
cd ~/docker/apps-stack && umask 077
grep -q '^AGENTS_TOKEN=' .env || printf 'AGENTS_TOKEN=%s\n' "$(openssl rand -hex 32)" >> .env
grep -q '^HOUSEHOLD_ID=' .env || echo "HOUSEHOLD_ID=<מזהה משק הבית>" >> .env
```

את מזהה משק הבית Claude שולף ממסד הנתונים (רק המזהה, בלי נתונים).

## 4. קובץ התיק — **Claude**, באישור שלך

שמות הנכסים, הסטופים והכללים לא נמצאים במאגר, כי המאגר ציבורי. הם יושבים בשרת:

```bash
mkdir -p ~/docker/apps-stack/agents/data
nano ~/docker/apps-stack/agents/portfolio.json
```

המבנה מופיע ב-[`agents/portfolio.example.json`](../agents/portfolio.example.json):

- `benchmark` — מדד הייחוס (S&P 500, ‏`^GSPC`).
- `holdings` — לכל נכס: שם, סמל ב-Yahoo (או `null` כשאין מקור), מטבע הסטופ, וסטופ אם יש.
- `watchlist` — נכסים שאתה עוקב אחריהם ועוד לא מחזיק. סוכן השוק סורק אותם מול
  התנאים הטכניים שבכללים (מעל ממוצע 200, ממוצע 50 מעל 200) וממיין לפי המרחק מעל
  ממוצע 200. סוכן המחקר בודק להם מועד דוח קרוב. הסוכנים לא מוסיפים לרשימה נכסים
  משלהם — אתה מרחיב אותה.
- `rules` — הכללים שלך כטקסט. הסוכן משווה אליהם; הוא לא מנסח אותם.

הקובץ נקרא מחדש בכל ריצה. עדכון סטופ או הוספה לרשימת המעקב לא דורשים הפעלה מחדש.

**סמלים:** כמו ב-Yahoo Finance. מניות אמריקאיות בלי סיומת (`INTC`), ת"א עם `.TA`
(`TEVA.TA`, ‏`TA35.TA`), מדדים עם `^` (`^GSPC`, ‏`^N225`). מניות ת"א מגיעות באגורות
ומומרות לשקלים, אז סטופ של טבע נכתב בשקלים. סטופ במטבע שונה ממטבע המחיר לא נבדק,
והסוכן מסמן את זה.

**פער ידוע:** קרנות סל של ת"א לפי מספר נייר (למשל 1159250) אינן ב-Yahoo. אפשר לעקוב
דרך המדד שהן עוקבות אחריו, עם `note` שמסביר.

## 5. השירות ב-compose — **Claude**

ב-`docker-compose.yml`, לשירות `oshit` הקיים נוסף רק הטוקן:

```yaml
  oshit:
    environment:
      AGENTS_TOKEN: ${AGENTS_TOKEN}
```

ושירות חדש:

```yaml
  oshit-agents:
    image: ghcr.io/saarcohenn/oshit-agents:latest
    container_name: oshit-agents
    restart: unless-stopped
    env_file: .env
    environment:
      OSHIT_URL: http://oshit:8080
    volumes:
      - ./agents/portfolio.json:/config/portfolio.json:ro
      - ./agents/data:/data
    depends_on:
      - oshit
```

- אין `ports`, ולכן אין התנגשות עם פורט קיים. `http://oshit:8080` הוא הפורט הפנימי של
  Osh.it ברשת של ה-stack — לא הפורט במחשב, שבו 8080 שייך ל-it-tools.
- השירות פונה החוצה בלבד: ל-Osh.it ברשת הפנימית, ל-Anthropic ול-Yahoo.
- העריכה נעשית בקובץ עצמו בשרת. stack חדש עם אותו תוכן (למשל ב-Portainer) יתנגש
  בשירותים שכבר רצים — באותם פורטים ובאותם שמות קונטיינרים.
- `env_file: .env` נותן לסוכנים את המפתח ואת הטוקן. ל-`oshit` מגיע רק הטוקן.
- הקונטיינר רץ כמשתמש `node` (uid 1000), ולכן `agents/data` נוצר מראש בצעד 4.

## 6. חבילת התמונה ציבורית — **אתה**, פעם אחת

אחרי שה-PR ממוזג והבנייה הראשונה של `oshit-agents` מסתיימת, GitHub יוצר את החבילה
כפרטית. השרת מושך בלי הזדהות, ולכן:

1. <https://github.com/users/saarcohenn/packages/container/oshit-agents/settings>
2. **Danger Zone → Change visibility → Public**.

הקוד ממילא פתוח, ו-`oshit` כבר ציבורית. בתמונה אין סודות: המפתח והתיק מגיעים מהשרת.

## 7. עדכונים אוטומטיים — **Claude**

אותו סקריפט שמעדכן את Osh.it, עם שני פרמטרים. ב-`crontab -e` נוספת שורה:

```cron
*/5 * * * * STACK_DIR=/home/saar/docker/apps-stack SERVICE=oshit-agents IMAGE=ghcr.io/saarcohenn/oshit-agents:latest /home/saar/bin/oshit-update >> /home/saar/oshit-agents-update.log 2>&1
```

## 8. הפעלה ובדיקה — **Claude**

```bash
cd ~/docker/apps-stack
docker compose up -d oshit oshit-agents
docker compose ps oshit-agents
docker logs --tail 20 oshit-agents
```

- בלוג צריך להופיע `oshit-agents פעיל`. אם מופיע "מצב המתנה" — המפתח לא נמצא ב-`.env`.
- במסך "סוכנים" הסטטוס משתנה ל"מחובר" תוך חצי דקה.
- "הרץ עכשיו" לכל סוכן. הדמות עוברת בין המצבים, הממצאים מופיעים בפיד, והעלות
  מוצגת בכרטיס הריצה.

## עצירה וביטול

| מה | איך |
|---|---|
| לעצור את הסוכנים | `docker compose stop oshit-agents` |
| לבטל את המפתח | ב-Console: **API Keys → Disable**. השירות יחזיר שגיאה בריצה הבאה, בלי לקרוס |
| להסיר הכול | למחוק את השירות מה-compose, את שורת ה-cron, ואת `ANTHROPIC_API_KEY` מ-`.env` |

## עלות ותקציב

- **עלות לכל ריצה:** שירות הסוכנים מחשב אותה לפי המודל שענה בפועל: קלט, פלט,
  קריאה וכתיבה למטמון, ו-10$ לאלף חיפושים. העלות נשמרת עם הריצה ומוצגת בכרטיס שלה.
- **תקציב חודשי:** נקבע במסך "סוכנים" (בעלים בלבד). הכרטיס מראה כמה הוצא מתחילת
  החודש לפי שעון ישראל, לפי סוכן ולפי מודל. כשההוצאה מגיעה לתקציב, ריצה חדשה נסגרת
  בהודעה בלי לקרוא למודל. ריצה שכבר רצה יכולה לחרוג בריצה אחת לכל היותר.
- **הבלם האחרון:** הסכום ב-Osh.it הוא הערכה לפי המחירון. תקרת ההוצאה ב-Console של
  Anthropic נשארת המקור הקובע.
- **הגנות נוספות:** תקרה של 8 סבבים לריצה, עד 8 חיפושים לריצת מחקר, וסוכן ההוצאות
  לא קורא למודל כשאין נתונים חדשים.

## היומן

המסך מציג את 50 הצעדים האחרונים, ואפשר להרחיב ל-250 או ל-1000. "הורדת היומן המלא"
מוריד קובץ טקסט עם כל מה שנשמר: שורה לכל צעד, בשפת המסך. ריצה נשמרת 90 יום, או 200
הריצות האחרונות של כל סוכן — מה שמשאיר יותר.

## שפה

כל סוכן כותב את הסיכום והממצאים בעברית ובאנגלית באותה ריצה. המסך באנגלית מציג
את האנגלית. התוספת לעלות היא כמה מאות טוקנים לריצה.
